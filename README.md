# Dockerized Flask Application

A simple Flask web application containerized using Docker as part of my Cloud & DevOps learning journey.

## 🚀 Project Overview

This project demonstrates how to package and run a Flask application inside a Docker container.

The application displays a simple message:

> Hello from my Dockerized Flask Application!
